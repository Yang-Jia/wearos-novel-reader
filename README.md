# 腕上书（Wear OS 小说阅读器）

一个面向 Wear OS 3+ 圆形表盘的小说阅读器。支持本地 TXT / EPUB 导入、Inbox 导入、分享导入和 Wi-Fi 浏览器传书；正文使用 `BoxInsetLayout` 安全区排版，支持分页与滚动阅读、章节切换、阅读进度保存和屏幕常亮。

- 应用名：腕上书
- 包名：`com.wear.novelreader`
- 版本：1.1
- 最低系统：Wear OS 3+ / Android 11（API 30）
- 目标版本：Android 14（API 34）
- 编译版本：Android 15（API 35）
- 技术栈：Kotlin、XML View、ViewBinding、`BoxInsetLayout`、`WearableRecyclerView`
- 构建环境：Gradle 8.7、AGP 8.6.1、Kotlin 1.9.24、JDK 17
- GitHub：[Yang-Jia/wearos-novel-reader](https://github.com/Yang-Jia/wearos-novel-reader)

## 功能总览

- 圆屏 `BoxInsetLayout` 安全区布局
- 本地 TXT / EPUB 导入
- Inbox 文件夹导入
- 其他 App 分享 / 打开文件导入
- Wi-Fi 浏览器传书
- Wi-Fi 传书地址二维码
- 上传/导入后书架实时刷新
- 分页阅读和滚动阅读双模式
- 滚动模式采用章节画布连续滚动，左右黑区也可滚动
- 预加载当前章节前后 2 章，切换章节优先命中缓存
- 四个主页面顶部常驻时间和电量
- 章节自动拆分、目录跳转、上一章 / 下一章
- 章节快速跳转：目录页右侧按钮或阅读菜单，按范围嵌套选择，确认后跳转
- 字号、行距、主题和正文字体颜色设置
- 阅读亮度调节：跟随系统或自定义 10%–100%
- 阅读进度自动保存（延迟合并写入）
- 阅读页底部显示页码/百分比
- 章节列表显示章节阅读进度
- 删除书籍支持 3 秒撤销
- 导入失败文件移入 `inbox/failed/`，避免启动反复重试
- 滚动与点击菜单带滚动提示
- 屏幕常亮
- 左边缘滑动返回
- 左右黑区点击翻页
- 正文全文分页，不截断、不省略

## 阅读界面

- 所有页面使用 `androidx.wear.widget.BoxInsetLayout`，内容位于圆屏内接安全区域。
- 阅读页不显示顶部章节标题行，正文占满安全区；底部仅显示小号页码/百分比
- 当前章节名、书名和阅读进度统一放在阅读菜单中查看。
- 阅读页当前只显示正文，减少圆屏上的无效内容。
- 阅读时屏幕保持常亮。

## 顶部状态栏

- 显示页面：书架、阅读页、章节列表、Wi-Fi 传书页
- 位置：圆形表盘顶部弧形黑区，正文安全方形之外
- 内容：当前时间 + 电池百分比
- 时间跟随系统 12/24 小时格式，每分钟自动更新
- 电量通过 `ACTION_BATTERY_CHANGED` 广播更新，只在页面可见时注册，百分比未变化时不重设文本
- 使用半透明深色圆角底，保证在不同阅读主题和菜单遮罩上可读
- 不新增权限，不轮询，不使用后台定时器
- 非圆屏设备自动隐藏
- 导入选择框、导入进度框、删除确认框等系统 Dialog 不显示状态栏
- 充电界面和系统弹窗属于系统窗口，不在应用状态栏范围内

## 阅读操作

### 分页模式

- 点击正文左侧区域：上一页
- 点击正文右侧区域：下一页
- 点击正文中间区域：打开菜单
- 在正文内左滑：下一页
- 在正文内右滑：上一页
- 点击正文方形左侧黑区：上一页
- 点击正文方形右侧黑区：下一页
- 菜单开启“反转”后，正文和左右黑区的点击方向互换：左侧下一页、右侧上一页
- 反转只影响点击/轻触，不影响左右滑动方向
- 翻到本章最后一页继续向后：自动进入下一章
- 翻到本章第一页继续向前：自动进入上一章最后一页

> 屏幕最左侧边缘的右滑手势优先用于返回，不会触发上一页。

### 滚动模式

- 上下滑动正文阅读
- 左右黑区的上下滑动也可以滚动正文，并支持惯性
- 旋转表冠按固定线性步长滚动，并通过逐帧平滑消除整数像素跳动
- 当前章节前后各 2 章预先读入内存，最多缓存 5 章；切章优先命中缓存
- 预加载任务只在前台运行，离开页面立即取消
- 章节之间连续滚动，不再整章替换；未加载的远处章节显示加载占位
- 第一章顶部和最后一章底部自然停止
- 点击正文任意位置打开菜单
- 通过菜单中的“上一章 / 下一章”切换章节；点“下一章”后再点“上一章”会回到离开前的阅读位置
- 滚动位置和阅读进度自动保存

### 返回

- 从屏幕最左侧边缘向右滑：返回
- 阅读页：返回书架
- 目录页：返回阅读页
- Wi-Fi 传书页：返回书架
- 主界面：退出应用
- 阅读菜单打开时：先关闭菜单，再次右滑才退出阅读页

## 阅读菜单

通过以下方式打开：

- 分页模式：点击正文中间区域
- 滚动模式：点击正文任意位置

菜单包含：

- 书名
- 当前章节
- 阅读百分比
- 目录
- 跳转章节
- 模式：翻页 / 滚动
- 上一章 / 下一章
- 反转：开 / 关，互换正文和左右黑区的点击翻页方向
- 字号− / 字号+
- 行距
- 主题：黑底 / 柔黑 / 米黄
- 字体颜色：进入独立色板页，选择后单行预览，点“完成”应用
- 屏幕常亮：开 / 关
- 亮度：进度条自定义，支持“跟随系统”
- 关闭

默认设置：

- 字号：14sp，可调范围 12–28sp
- 行距：1.2，可在 1.2 / 1.35 / 1.5 / 1.7 之间循环
- 默认主题：黑底
- 默认正文字体颜色：跟随主题
- 默认屏幕常亮：开
- 默认反转：关
- 反转仅影响点击/轻触，左右滑动仍保持正常方向
- 默认亮度：跟随系统
- 自定义亮度范围：10%–100%
- 阅读设置保存在 `SharedPreferences`

### 正文字体颜色

- 阅读菜单中的“字体颜色”打开独立颜色页。
- 颜色页显示一行正文预览，点击色块只更新预览，点“完成”才保存并返回。
- 只修改章节正文颜色，菜单、状态栏和页码仍跟随阅读主题。
- “跟随主题”清除自定义颜色，恢复当前主题默认正文色。
- 自定义颜色独立保存，切换主题后仍保留。

### 性能与省电

- 阅读进度写入做了节流：
  - 翻页/滚动停止后延迟 2.5 秒写入
  - 连续翻页只保留最后一次
  - 延迟保存只在前台执行；`onPause` 和退出阅读页时提交并等待最后一次进度写入
  - 进度文件由仓库的单线程写队列串行原子替换，避免主线程直接落盘和并发覆盖
- 分页绘制按当前页单独构建小布局，只绘制当前页文字，不再每次扫描整章
- 阅读页支持降低窗口亮度，减少 OLED 屏幕功耗
- 书库首次加载时扫描一次，之后使用内存缓存和已排序快照；书架回到前台不再逐本读取书籍文件
- 书库变更通过 `SharedFlow` 通知书架，Wi-Fi 上传和阅读进度保存后无需切页即可刷新
- 书架使用版本号判断数据是否变化，未变化时不再重复提交和计算 DiffUtil
- 书架使用 `DiffUtil` 局部更新，只刷新发生变化的书籍
- 关闭书架和目录的 ItemAnimator，减少无意义动画和重绘
- 阅读页使用不透明窗口背景，移除根布局重复底色，只保留一层全屏背景
- 书架、目录和 Wi-Fi 页背景统一由窗口背景提供，减少过度绘制
- 书库根目录变化时自动失效缓存；通过外部方式增删书籍也能在下次回到书架时发现
- 删除书籍先原子移入隐藏的 `.trash-*` 目录；撤销窗口结束或离开书架页时完成删除，删除失败时不会显示无效的撤销
- 取消导入时立即清理当前 `.tmp-*` 工作目录，不在后台继续解析
- 书架按最近阅读或导入时间排序
- 书架、目录和 Wi-Fi 页保持屏幕常亮；阅读页可通过菜单“屏幕常亮”开关控制

## 章节快速跳转

- 目录页右侧安全区外有竖排“跳转”按钮；阅读菜单也有“跳转章节”。
- 跳转页按当前书章节数自动分组：
  - 893 章：每 100 章 → 每 10 章 → 单章
  - 40000 章：每 10000 章 → 每 1000 章 → 每 100 章 → 每 10 章 → 单章
- 非叶子项显示章节范围和子范围数量；单章项显示完整章节标题，长标题自动换行。
- 顶部面包屑可返回任意上级范围。
- 点击单章后显示确认页，确认后才返回阅读页并打开目标章节；确认前可返回重新选择。
- 从目录页进入时，跳转后返回 Reader；从阅读菜单进入时直接加载章节。

## 本地导入

主界面点击“导入”后，会先弹出导入方式选择框：

1. 系统文件选择器
2. 从 Inbox 导入
3. Wi-Fi 传书

### 1. 系统文件选择器

- 使用 Android Storage Access Framework 多选文件
- 支持 `.txt` 和 `.epub`
- 导入前会校验扩展名
- 文件会先复制到应用缓存，再解析入库
- 原始文件不会被删除；导入完成后只清理应用缓存中的临时副本
- 如果手表没有可用的系统文件选择器，会提示改用 Inbox 或 Wi-Fi 传书

### 2. Inbox 导入

Inbox 路径：

```text
/sdcard/Android/data/com.wear.novelreader/files/inbox/
```

流程：

- App 启动后首次进入主界面时自动扫描一次 Inbox
- 也可以手动点击“从 Inbox 导入”
- 只识别 `.txt` 和 `.epub`
- 导入成功的文件移动到：

```text
/sdcard/Android/data/com.wear.novelreader/files/inbox/imported/
```

- 导入失败的文件会移动到：

```text
/sdcard/Android/data/com.wear.novelreader/files/inbox/failed/
```

- 如果失败文件移动失败，则保留在 Inbox 原位置，方便排查
- 导入被取消时，文件保留在 Inbox 原位置
- Inbox 和 Wi-Fi 传书使用不同目录

### 3. 分享 / 打开导入

- 支持其他 App 通过 `ACTION_SEND` 分享 TXT / EPUB
- 支持 `ACTION_VIEW` 打开 `content://` 或 `file://` 文件
- 只读取来源 URI，不会删除或移动分享来源文件
- 与系统文件选择器共用同一套解析、清洗和入库流程

### 4. 导入限制

- 单个文件最大 80MB
- 同一文件重复导入会生成一本新书，目前不做去重
- EPUB 不支持 DRM / 加密文件
- 导入失败会显示文件名和错误原因

## TXT / EPUB 解析

### TXT

- 自动识别编码：
  - UTF-8
  - UTF-8 BOM
  - UTF-16LE / UTF-16BE
  - GB18030 / GBK
- 支持 `\r\n`、`\n`、`\r` 换行
- 章节标题识别：
  - `第X章`
  - `第X回`
  - `第X节`
  - `第X卷`
  - `第X部`
  - `第X集`
  - `第X篇`
  - `序章`、`序言`、`楔子`、`引子`、`前言`
  - `后记`、`尾声`、`终章`、`大结局`、`番外`
  - `Chapter N`
- 没有章节标题时，按长度自动分节
- 每个非空行作为一个段落
- 书内“书名：”“作者：”等元数据行会被识别并从正文中移除
- 导入时按 8000 字左右分块，避免单章过大

### EPUB

- 解析 `META-INF/container.xml`
- 解析 OPF 中的 metadata、manifest、spine
- 按 spine 顺序提取正文
- 跳过 `nav` 文档和目录页
- 自动过滤“目录 / Contents / Table of Contents”
- 忽略图片、CSS、封面和复杂排版，只保留文字
- 章节标题优先取正文中的 `h1`–`h6`
- 元数据缺失时使用文件名和“第N章”兜底
- 检测到 DRM / 加密内容时会提示无法导入
- 对 ZIP 条目大小有限制，避免异常压缩包导致内存问题

## 正文清洗规则

导入 TXT 和 EPUB 时都会统一清洗正文。

规则：

- 删除所有空行
- 段落之间只保留单个换行
- 每个正文段落开头统一两个全角空格：

```text
　　（U+3000 U+3000）
```

- 清除段落开头原有的：
  - 半角空格
  - 全角空格
  - Tab
  - 不间断空格（NBSP）
- 清除段落末尾空白
- 章节标题保持顶格，不缩进
- 段落内部空格、标点、对话引号保留
- TXT 每个非空行作为一个段落
- EPUB 按 HTML 块 / 空行拆段，块内因排版产生的换行会合并
- 章节之间不再追加空行
- 原始缩进不会叠加，最终只保留统一的 `　　`

示例：

清洗前：

```text
    第一段


　　第二段
```

清洗后：

```text
　　第一段
　　第二段
```

注意：

- 清洗只对**之后新导入**的书生效
- 已有书籍不会自动重新清洗
- 要清理旧书，请删除后重新导入

## Wi-Fi 传书

### 使用步骤

1. 手表连接 Wi-Fi
2. 电脑或手机连接同一个 Wi-Fi
3. 手表打开“Wi-Fi 传书”
4. 浏览器访问手表显示的地址：
   ```text
   http://手表IP:8080
   ```
5. 也可以点右上角二维码按钮，用手机扫码打开
6. 在网页中拖拽或选择 TXT / EPUB
7. 上传完成后自动解析、清洗并加入书架

### 服务说明

- 使用前台服务运行，离开传书页面会自动停止服务；重新进入页面会再次启动
- 正在上传或解析时按返回/左边缘返回，会先确认是否中断上传并退出
- 退到桌面或切到其他应用时直接停止服务，不弹确认
- 停止方式：
  - 传书页面点击“停止服务”
  - 系统通知中点击“停止”
  - 按返回或左边缘返回离开页面
- 端口从 8080 开始，若被占用会自动尝试后续端口
- 页面支持：
  - 拖拽上传
  - 多文件上传
  - 上传进度
  - 已导入书籍列表
  - 自动刷新书架
  - 地址二维码

### 二维码

- Wi-Fi 服务运行且获得地址后，右上角二维码按钮启用。
- 二维码编码当前地址列表中的第一个 `http://IP:端口`。
- 点二维码按钮显示白底二维码、对应 URL 和关闭提示。
- 点二维码以外的空白区域或按返回关闭二维码，不退出传书页。
- 二维码在本地即时生成，不联网、不启动后台任务；退出页面时自动关闭并释放 Bitmap。
- 使用 ZXing core 生成二维码，不引入额外 Activity、Service 或 Receiver。

### IP 获取

通过 `ConnectivityManager` 和 `NetworkInterface` 获取局域网 IPv4 地址。

注意：

- 手表只通过蓝牙连接手机、没有实际 Wi-Fi 时，可能没有局域网 IP，需要先在手表设置中开启 Wi-Fi。
- 如果 IP 为空，传书页面会显示“当前没有可用的局域网 IP，请检查手表 Wi-Fi”。

### HTTP 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 上传页面 |
| GET | `/api/books` | 当前书架 JSON |
| GET | `/health` | 健康检查 |
| POST | `/upload` | multipart 文件上传 |

### 安全说明

- 服务仅面向局域网使用
- 当前没有账号或密码验证
- 不要将端口暴露到公网
- 文件名会做安全清理，但上传页面本身不做用户认证
- 单个 HTTP 上传请求限制 80MB，最终导入仍受 80MB 文件限制
- 超过限制的上传在读取正文前直接返回 413 中文提示
- 上传临时文件在导入完成后删除

## 存储位置

应用使用私有内部存储保存图书馆，普通文件管理器无法直接访问。

| 内容 | 路径 | 是否保留 |
|---|---|---|
| 本地导入缓存 | `/data/user/0/com.wear.novelreader/cache/uri-import/` | 导入后删除 |
| Wi-Fi 上传缓存 | `/data/user/0/com.wear.novelreader/cache/wifi-uploads/` | 导入后删除 |
| Inbox 目录 | `/sdcard/Android/data/com.wear.novelreader/files/inbox/` | 成功后移入 imported |
| Inbox 已导入 | `/sdcard/Android/data/com.wear.novelreader/files/inbox/imported/` | 保留 |
| 正式书库 | `/data/user/0/com.wear.novelreader/files/library/<书籍ID>/` | 保留 |
| 书籍元数据 | `meta.json` | 保留 |
| 章节正文 | `chapters/0001.txt` 等 | 保留 |
| 阅读进度 | `progress.json` | 保留 |

补充：

- 原始 TXT / EPUB 文件不会保留
- 只保留解析和清洗后的章节文本
- 调试安装可用 adb 查看：
  ```text
  adb shell run-as com.wear.novelreader ls files/library
  ```
- 导入过程中的临时工作目录位于书库根目录下的 `.tmp-*`，成功后重命名为正式书籍目录

## 数据结构

每本书对应一个目录：

```text
files/library/<bookId>/
  meta.json
  progress.json
  chapters/
    0001.txt
    0002.txt
    ...
```

`meta.json` 主要内容：

```json
{
  "id": "书籍ID",
  "title": "书名",
  "author": "作者",
  "format": "txt 或 epub",
  "addedAt": 0,
  "chapters": [
    {
      "title": "章节名",
      "file": "0001.txt",
      "chars": 1234
    }
  ]
}
```

`progress.json` 主要内容：

```json
{
  "chapterIndex": 0,
  "charOffset": 0,
  "updatedAt": 0
}
```

- 章节文件使用 UTF-8
- 阅读进度按“章节下标 + 章内字符偏移”保存
- 字号或模式切换后仍能按字符偏移恢复阅读位置
- 书架按最近阅读或导入时间排序
- 书库在内存中缓存，导入、删除、阅读进度保存后同步更新缓存和版本号

## 权限与系统特性

Manifest 中声明：

- `android.permission.INTERNET`
- `android.permission.ACCESS_NETWORK_STATE`
- `android.permission.ACCESS_WIFI_STATE`
- `android.permission.POST_NOTIFICATIONS`
- `android.permission.FOREGROUND_SERVICE`
- `android.permission.FOREGROUND_SERVICE_DATA_SYNC`

特性：

- `android.hardware.type.watch`：必需
- `android.hardware.wifi`：可选

Android 13+ 会请求通知权限，用于 Wi-Fi 传书前台服务通知。

Wi-Fi 传书服务类型为 `dataSync`，用于保证上传期间服务不被系统回收。

### 后台行为

- 没有开机广播、JobScheduler、AlarmManager、WorkManager 或其他自启动入口。
- Wi-Fi 前台服务只在传书页面可见时运行，离开页面立即停止并移除通知。
- 离开主界面会取消正在进行的导入、书架刷新和临时文件清理，并停止导入解析；当前导入的 `.tmp-*` 工作目录会立即清理。
- 离开 Wi-Fi 页面会取消正在进行的上传解析，删除临时上传文件；已完成的书籍保留。
- 阅读页的延迟进度保存只在前台运行；`onPause` 提交并等待最后一次写入完成，进度文件通过仓库单线程写队列串行原子替换。
- 顶部时间/电量接收器只在页面可见时注册；时间由 `ACTION_TIME_TICK` 每分钟更新，不使用常驻定时器。
- 已移除 `ProfileInstaller` 的 Startup Provider/Receiver，并关闭 Auto Backup。
- 删除书籍先移入隐藏的 `.trash-*`；离开书架页会明确完成当前删除，清理失败时不会显示无效的撤销。
- Android 仍可能缓存空的应用进程，但不会执行应用代码、服务、线程、接收器或文件 IO。

## 已知限制

- EPUB 只提取文字，不保留图片、封面、样式和复杂排版
- 不支持 DRM / 加密 EPUB
- 本地文件选择器不是所有手表系统都有
- 部分手表需要先开启 Wi-Fi 才能获得局域网 IP
- Wi-Fi 传书需要电脑/手机和手表在同一个局域网
- 应用内暂不提供书籍导出功能
- 重复导入同一个文件会生成重复书籍
- 已导入的旧书不会自动重新清洗
- Auto Backup 已关闭，卸载重装不会通过系统备份恢复书库和进度
- 不支持书内搜索、书签、批注
- 部分 OEM 手表可能限制前台服务通知显示
- 部分 OEM 手表可能忽略应用内窗口亮度设置
- 书架、目录和主界面仍会保持屏幕常亮，耗电高于仅阅读页常亮
- 顶部时间和电量不会显示在系统 Dialog、充电界面等独立窗口中
- 通过 adb 等外部方式直接增删书库目录后，下次回到书架会自动发现；直接修改 meta/progress 内容仍需重启 App
- 充电时手表系统可能显示充电界面，这不是应用页面

## 常见问题

### Wi-Fi 传书页面没有显示 IP？

请确认：

1. 手表已连接 Wi-Fi
2. 电脑/手机连接同一个 Wi-Fi
3. 手表不是仅通过蓝牙代理联网

### 网页显示导入成功，但书架没有更新？

当前版本已通过书库变更通知自动刷新书架，Wi-Fi 上传完成后无需切换页面，新书会出现在书架顶部。如果仍未出现，请确认上传返回成功，并重新打开书架页面。

### 原始 TXT / EPUB 文件在哪里？

不保留。导入时会将源文件解析为章节文本，原始文件在导入完成后删除。

### 为什么旧书的段落格式没有变化？

正文清洗只对之后新导入的书生效。请删除旧书后重新导入。

### 顶部时间和电量在哪里显示？

显示在书架、阅读页、章节列表和 Wi-Fi 传书页顶部的弧形区域。导入选择框、导入进度框、删除确认框等系统 Dialog 不显示。

### 亮度调节没有效果？

部分手表 OEM 会忽略应用内的窗口亮度覆盖，此时仍会跟随系统亮度。可以尝试系统设置中的亮度调节。

### 为什么翻页后进度没有立刻写入文件？

阅读进度采用延迟合并写入，通常延迟约 2.5 秒；退出阅读页或切到后台时会立即保存。

### 如何查看应用内部书库？

调试安装可以通过 adb：

```text
adb shell run-as com.wear.novelreader ls files/library
```

普通文件管理器无法访问应用私有目录。

### 为什么书架出现重复书籍？

当前没有按文件内容去重，重复导入会创建新书。长按书籍可以删除。

### 如何停止 Wi-Fi 传书？

- 按返回或左边缘返回离开传书页面
- 在 Wi-Fi 传书页面点击“停止服务”
- 或在系统通知中点击“停止”
- 退到桌面或切换到其他应用也会自动停止
- 上传中离开会弹窗确认是否中断上传

### 为什么阅读页没有页码和章节标题了？

这是当前界面设计：正文占满安全区，章节名和进度移到阅读菜单中查看。点击正文中间（滚动模式为任意位置）可打开菜单。

### 本地导入会删除原文件吗？

- 系统文件选择器、系统分享或打开方式导入：不会删除原文件，只复制到应用缓存，导入结束后清理缓存副本。
- Inbox 导入：会把文件移动到 `inbox/imported/` 或 `inbox/failed/`，不是直接删除；取消导入时文件保留在 Inbox 原位置。
